# UI 界面设计说明

依据：`lab2/modules.md` 的模块划分和 `lab1/requirements.md` 的需求。
风格参考本人提供的登录页示例，但没有照抄：
- 背景是天空蓝渐变加白云；
- 卡片是半透明毛玻璃，大圆角，白色描边；
- 标题用深蓝粗体并带白色光晕；
- 主按钮为蓝色渐变；
- 吉祥物是一只趴在卡片边缘的猫耳小云团。

制作方式：界面源文件放在 `lab2/ui-src/`（HTML + CSS），用 `render.sh` 调用无界面 Edge 截图，导出到 `lab2/UI界面/`。桌面画布为 1440×1024；手机画布为 390×844，按 2 倍分辨率导出。

状态颜色约定：
- 报名成功、通过：绿；
- 候补中、候补凭证：橙；
- 已取消、已失效、已结束：灰；
- 缺席、驳回、错误：红；
- 进行中、申办：蓝。

## 界面1 登录 / 注册

登录卡片居中，可在“登录”和“注册”之间切换，下方是账号、密码和“登录”按钮。自行注册只能成为参与者；组织者、检票员和管理员的账号由平台分配。底部卡片提供“游客浏览”入口：游客无需登录即可浏览活动、发表评论和回复。

## 界面2 活动广场

**筛选条**：顶部一行可以组合四种条件：分类标签、日期范围、状态下拉、关键词搜索。切换条件时只刷新右侧列表，保留输入内容和浏览位置。

**左栏**：“本周值得期待”按开始时间推荐已发布的场次。

**右侧卡片**：每张卡片显示时间、地点、剩余名额进度条和状态标签（报名中、已满可候补、进行中、已结束、已取消），以及收藏星标。已结束和已取消的活动排在后面，并整体置灰。

## 界面3 活动详情与报名

**左侧：活动信息、评分和讨论区。**
- **评分**：显示五星制平均分（保留一位小数）和评价人数；“我的评分”在活动结束前不可用。
- **讨论区**：任何人都能发表评论和回复，作者名旁的标签区分游客、已出席和活动官方。参与者可以给他人评论点赞，回复缩进显示在被回复评论下方。

**右侧：报名面板。**
- 先选场次和票种，每个票种显示剩余名额，已满的标“已满·可候补”。
- 主按钮随状态变化：立即报名、加入候补、已报名查看票券、报名已截止。下方列出这几种状态的示意。
- 面板中列出报名截止、退票截止、检票开始三个时间点，并有收藏按钮。

## 界面4 我的票券

正式票和候补凭证用颜色和文字明确区分：
- 正式票：显示票码和“可入场”；
- 候补凭证：显示“第 2 位·不可入场”，递补后自动换发正式票。

失效记录整张卡片置灰，可以用“清理失效记录”从个人列表中移除，不会删除后台历史。

点击“退票”后，底部弹出确认面板，说明票码将立即失效、名额会按顺序释放给候补者；检票开始后不能再退票。

## 界面5 消息与收藏

成功进入候补后，页面顶部出现橙色横幅，提醒“新消息”；消息分段的标签上显示未读数。

消息正文注明“候补不代表已获得入场名额”，避免误解。

收藏列表按收藏时间倒序排列。已取消或已结束的活动仍然保留（置灰），只有用户主动点“取消收藏”才会移除。

## 界面6 检票

- 检票员只能选择已授权的场次，页面显示检票时间窗口。
- 输入票码后点击“核验”，结果用三种颜色表示：
  - 绿色：通过；
  - 橙色：已签到，显示首次签到时间，不重复计数；
  - 红色：候补凭证、非本场次或无效票码。
- 底部显示本场已签到人数和应到人数。
- 断网时页面顶部出现红色横幅，暂停核验并自动重试。

## 界面7 活动编辑

**表单**：分为基本信息、时间设置、场次与票种三组。
- 时间设置旁列出规则：检票开始不晚于活动开始；退票必须在检票开始前；本期只提供免费票。
- 名额填 0 时，输入框标红并提示“名额须为正整数”。

**驳回提示**：活动被驳回时，页面顶部的红色提示条显示管理员给出的原因。

**按钮随状态变化**：草稿可以“保存草稿”和“提交审核”。发布后只能“申请修改”或“取消活动”，名额只增不减。

## 界面8 名单统计与检票安排

**统计卡片**：显示总容量、报名成功、候补中、已签到、已取消、缺席和签到率，并注明计算口径（占用 = 成功 + 已签到 + 缺席）。

**名单表格**：包含所有状态，可以按姓名或状态筛选，并导出 CSV。

**检票安排**：右侧勾选检票员。未分配检票员的场次会显示黄色提示：发布活动不会自动授予检票权限。

## 界面9 审核台

**待审核列表**：申办和修改两类申请放在同一列表中。

**修改申请详情**：用前后对比表展示，变化的字段高亮。系统先做校验，例如名额只增未减、检票开始不晚于活动开始，并预告审核通过后将递补的候补人数。

**审核操作**：驳回时必须填写原因。审批时还会再次核对活动版本，防止覆盖已经变化的数据。

## 界面10 平台统计与操作日志

**平台统计**：卡片汇总活动数、占用名额、候补人数、签到人数和签到率，柱状图显示各分类的占用名额。

**操作日志**：可以按操作者、动作和对象查询，结果列区分成功、重复请求、进入候补等情况。例如：
- 取消活动的记录显示“清空候补 8 人”；
- 重复检票显示“返回首次结果”。
